# AyurPass – User Journeys

## First-Time Consumer Journey (Extended)

### 1. Download & Onboarding (React Native)
- App Store / Google Play → Sign up (email, Apple/Google, phone)
- Quick profile setup (location, preferences)

### 2. Prakriti Constitution Quiz
- Interactive Vedic-science questionnaire (30–40 questions)
- AI/rule-engine scores Vata/Pitta/Kapha
- Results stored in `health_profiles`

### 3. Personalized Dashboard
- AI-driven recommendations (dosha-balanced daily routine, suggested services/products)
- “Today’s Balancing Ritual” feature

### 4. Discovery & Booking
- Search/map with filters (dosha compatibility, price, rating, availability, virtual/in-person, luxury tier)
- View Center Brand Profile (photos, videos, team) and Professional Profile (credentials, reviews, video intro)
- Select service → Real-time calendar (Google Calendar + internal availability)
- Add to cart or instant book
- Package builder for multi-session journeys

### 5. Checkout & Payment
- Transparent breakdown (service + taxes + platform fee)
- Stripe payment (Apple Pay/Google Pay supported)
- Split handled automatically via Stripe Connect

### 6. Post-Booking
- Confirmation with calendar add
- Reminders (SMS/push via Twilio)
- Pre-arrival instructions (dosha-specific prep)
- In-app check-in
- Post-service review + health notes update
- AI follow-up recommendations

### 7. Extended Features (Advanced)
- Browse & book **Packages** and **Treatment Plans**
- Granular **Consent Dashboard** approval before booking
- Ongoing Treatment Plan dashboard with progress tracking
- Full access to personal wellness history (with consent controls)
