# AyurPass – Executive Overview

**Full-stack, dual-sided premium wellness ecosystem**

AyurPass unifies Ayurveda (consultations, Panchakarma, herbal therapies), Yoga (classes, private sessions, retreats), Luxury Spas (treatments, wellness packages), and Meditation (guided sessions, retreats) under one intelligent platform.

## Key Differentiators
- Verified Professional Profiles (Vaidyas, Yoga instructors, spa therapists, meditation guides)
- Center/Brand Profiles with rich media and virtual tours
- Services + Products Marketplace with dosha compatibility tagging
- AI-Powered Personalization (Prakriti assessment + ongoing dosha balancing)
- Hybrid Experiences (in-person, virtual, hybrid)
- B2B SaaS Tools for providers (scheduling, staff, analytics, marketing automation)
- Strong emphasis on privacy, consent, and Vedic authenticity

## Tech Foundation
- **Consumer App**: React Native (iOS + Android)
- **Provider Dashboard + Marketing Site**: Next.js
- **Backend**: Node.js / NestJS
- **Database**: PostgreSQL (Prisma ORM) + Redis
- **Infrastructure**: AWS/GCP (HIPAA-eligible)
- **Payments**: Stripe Connect
- **Telehealth**: Twilio Programmable Video

## Monetization
- Marketplace commission: 15–22%
- Tiered SaaS subscriptions for providers: Starter ($149/mo), Growth ($349/mo), Enterprise (custom)
- Product marketplace commissions (10–15%)
- Premium listings, data insights, white-label solutions
